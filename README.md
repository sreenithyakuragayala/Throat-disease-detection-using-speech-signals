# Throat Disease Detection Using Speech Signals
## 📌 Project Overview
Throat Disease Detection Using Speech Signals is a machine learning and deep learning-based application designed to analyze voice recordings and classify them as healthy or potentially diseased. It uses speech signal processing and a CNN-BiLSTM model to identify patterns in voice samples.
## 🎯 Objectives
* Analyze voice recordings using speech signal processing.
* Extract important voice features such as MFCCs, pitch, jitter, shimmer, and formants.
* Classify voice samples using a trained CNN-BiLSTM model.
* Display prediction results and confidence scores.
* Provide a user-friendly web interface for voice analysis.
## 🛠️ Technologies Used
* Python
* TensorFlow / Keras
* CNN-BiLSTM Deep Learning Model
* MFCC Feature Extraction
* Flask
* HTML, CSS, JavaScript
* WAV Audio Files
## ✨ Key Features
* User registration and login
* Separate user and admin roles
* Voice sample upload in WAV format
* Healthy and potentially diseased voice classification
* Prediction confidence scores
* Prediction history
* PDF report generation
* Health tips and recommendations
## ⚙️ Project Workflow
1. Upload a voice recording in WAV format.
2. Preprocess the audio signal.
3. Extract relevant speech features.
4. Analyze the features using the trained CNN-BiLSTM model.
5. Display the predicted class and confidence score.
6. Save prediction history and generate reports.
## 📂 Model Information
The trained model is saved as `final_cnn_bilstm.h5`.
